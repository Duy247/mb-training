# MB Training for Karate Framework

## Run

```powershell
.\gradlew runIde
```

This starts a sandbox IntelliJ instance with the plugin loaded.

## What is included

- IntelliJ Platform plugin scaffold with Kotlin + Gradle
- Tool window: `MB Training`
- Interactive training path with:
  - exercises
  - missions
  - tasks
  - homework
- Basic-to-advanced curriculum examples for Karate Framework learning
- Completion tracking persisted across IDE restarts
- Tools menu action: `Open MB Training for Karate`
